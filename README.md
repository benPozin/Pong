# Pong Game (Python)

A simple Pong game built in Python using Pygame. Control the paddles to hit the ball and compete for the highest score.

## Technologies
- **Python** - Main programming language  
- **Pygame** - Used for rendering graphics and handling game logic  

## Prerequisites
- Python 3.8 or higher
- Git (for cloning the repository)

## Features
- Paddle movement using keyboard controls
- Ball speed increases after hitting a paddle
- Score tracking system
- Collision detection (Ball bounces off walls and paddles)
- Restart the game after scoring

## How to Run
1. **Ensure Python is installed**:  
   Verify with `python --version`

2. **Clone the repository**:  
   ```
   git clone https://github.com/benPozin/PongGame.git
   ```
3. **Navigate into the project folder**:
   ```
   cd Pong
   ```
4. **Install Pygame** (if not installed):
   ```
   pip install pygame
   ```
5. **Open the project** in Pycharm, Eclipse, or VS Code.
  
6. **Run the game**:  `python main.py`

## Controls
- **W / S** - Move the left paddle up/down  
- **UP / DOWN Arrow Keys** - Move the right paddle up/down
